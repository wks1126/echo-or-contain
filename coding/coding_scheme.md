# 编码总表（coding scheme overview）

用途：本论文（外交部记者会同题—发言趋同）语料标注的统一编码方案。
性质：**上下文特征**为确定性机器规则（可复现）；**任务变量（T1/T2/T3）**由人工/双编码者对正式信度集执行，本文档给出判定标准与示范答案（gold-demo）。

---

## 表 1. 人工任务编码变量（双编码者须标注）

| 变量 | 简称 | 取值 | 定义 | 主要判据 | 示例（来自语料） |
|---|---|---|---|---|---|
| **沿用度 / Echo** | `echo` | `2 / 1 / 0` | 答句在**词汇—措辞层面**承接/复用提问用词与核心表述的程度（不计是否同意） | `2` 明显沿用：照用提问的核心词/专名/机构名表述；`1` 部分沿用：用了实体或部分表述但主体转官方口径；`0` 几乎不复用，改用套语/重述 | `2`：「闫文滨大使…任命…」被答句近乎逐字复述；`0`：美制裁中国公司之问，答以「坚决反对…长臂管辖」不复用提问词 |
| **回应功能 / Function** | `function` | `A/B/C/D/E/F` | 回答**实质内容功能** | 见下表 2 分条 | A：给出具体事实/证实；C：「我没有可以提供的信息」 |
| **拒答 / Avoid（复核）** | `avoid_re` | `是 / 否` | 是否以「拒答式/程序性」回应而未提供实质 | 命中拒答套语：没有信息/无可奉告/建议问主管部门/不掌握/不了解…；或仅「将适时发布/请关注」 | 是：「建议向中方主管部门询问」 |

`echo` 与算法指标的关系（效度）：`mirror`(词法沿用率) 与人工 `echo` 正相关；`cos_sem`(语义余弦) 反映主题贴近，二者互补、分开报。

## 表 2. 回应功能（function）分条

| 代码 | 名称 | 判据 | 提示 |
|---|---|---|---|
| `A` | 提供具体信息/证实 | 给具体事实/数字/人员/日期/措施，明确证实或提供 | 不含强拒绝 |
| `B` | 部分/间接回应 | 有限回应：「正在了解/将适时发布/请关注/愿保持沟通」 | 未给实质也未完全拒 |
| `C` | 拒绝提供/拒答 | 「没有信息/不掌握/不了解情况/无可奉告/建议问主管部门/已多次回答」 | 词面拒答即 C，哪怕后面补一句立场 |
| `D` | 纠正/否定提问预设 | 驳斥提问或所涉方主张：「不是事实/坚决反对…指控/无中生有/错误/污名化」 | 是否定提问框架而非陈述 |
| `E` | 反问/施压提问方 | 直接反问/斥责提问方或其媒体立场（中文发言罕见） | 对第三方（如别国）批评≠E，多为 D/F |
| `F` | 立场表述（无实质新信息） | 套语式原则重申：「中方一贯/我们主张…」无数据无具体 | 最常见的"官方口径"类 |

## 表 3. 上下文特征（确定性机器规则，供分组/背景，非人工任务）

| 变量 | 取值 | 规则 | 备注 |
|---|---|---|---|
| `media` | `cn / foreign` | 由提问机构名单判定（央视/新华社/中新社…=cn；路透/法新/彭博/NHK…=foreign） | 确定性、可复现 |
| `sensitive` | `0 / 1` | 问句是否命中涉华争议议题词典（台湾/西藏/新疆/香港/南海/人权/关税/芯片/军事/核/制裁…） | 关键词词典公布 |
| `q_china` | `0 / 1` | 问句是否含 中国/中方/我国 | — |
| `avoid` | `0 / 1` | 答句是否命中拒答套语词典 | 与表1 `avoid_re` 同一套词，作信度复核参照 |

## 表 4. 正式信度集构成

| 项 | 值 |
|---|---|
| 来源 | 483 篇 × 4005 问答对 分层抽样 |
| 规模 | **92 条**（按 media × sensitive 分层，并**过采样 avoid 至 40 条**） |
| 字段 | id / date / who / media / sensitive / avoid(机器) / cos_sem / mirror / Q / A + 编码者填空列 `C1_echo`,`C1_function`,`C2_echo`,`C2_function` |
| 任务 | 每位编码者标 `echo`(2/1/0) 与 `function`(A–F)；另对 `avoid` 复标是/否 |
| 信度统计 | 双编码间 Cohen's κ（echo/function/avoid）；算法 vs 人工：Spearman(mirror,echo)、Spearman(cos,echo) |

## 使用说明（示范答案的地位）
- 逐条示范答案见 `coding_demo_answers.csv`（全 92 行，含 echo/function/avoid 建议与判据理由）与 `coding_demo_table.md`（可读版）。
- **示范答案为研究助手按本手册规则生成的建议（gold-demo），用于编码者培训与校准；不替代两位人类编码者的独立标注。** 正式 κ 与效度以两位人类编码者的标注计算。若某条示范与您的理解不符，请以您与第二位编码者的独立判断为准，并在分歧处回读本手册。

## 预填说明（coding_validation_samples.csv）
- `C1_echo` / `C1_function`（及 `C1_echo_reason` / `C1_function_reason`）已**由研究者/金标准参考预填**（= 上文示范答案，含抽样人工校正）。
- `C2_echo` / `C2_function` **留空**，须由第二位独立编码者在不看 `C1` 的前提下按本手册填写。
- **信度口径**：报 `C1–C2` 的 Cohen's κ（echo、function、avoid）作为编码者与金标准的一致性，并在方法部分如实说明 C1 为研究者/规则金标准参考、C2 为独立第二人；若期刊要求"两名互盲人类编码者间的 inter-rater κ"，则请让两位人类编码者各自独立填 `C1` 与 `C2` 后再算（此时可先清空 `C1` 预填值）。
