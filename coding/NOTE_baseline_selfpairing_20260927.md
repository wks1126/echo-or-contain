## 一、已改（明确写错）：§3.2 的「有序线性加权 κ = 0.890」

- **原因**：`reliability.py` 里 `exp = p.sum(0) * p.sum(1)` 得到的是向量而不是外积矩阵，
  与 (3,3) 权重矩阵广播后分母失真 → 0.890。
- **正确值**：距离加权线性 κ = **0.835**（与 `sklearn.cohen_kappa_score(..., weights='linear')`
  两套独立实现一致）；标称 κ = 0.831 本来就对。
- **正文已改为**：`echo Cohen's κ = 0.831 (percent agreement .90; with linear disagreement
  weights, κ_w = 0.835)`
- 影响面：仅该括注；function κ = 0.937、Bootstrap 区间、其余统计均不受影响。
- 详见库内 `02_编码与标注\JLP04_记者会趋同\⚠_口径更正_reliability_linear_kappa_20260927.md`。

## 二、待你决定：同场置换基线是否排除「自配对」

**现象**：摘要与 Table 2 首行写的是"semantic 0.611 vs. 0.395（d = 1.24）"。实测存档脚本
`build_all.py` 生成这个 0.395 时是 `perm=idxs; random.shuffle(perm)`，**没有排除自配对**
（即偶尔把某个问题配到它自己的答案上，cos 自然很高）。而 §3.3 的方法段写的是
"always excluding self-pairing"，`baseline_strict.py` 的三层严格基线也确实逐行排除了自配对。

**量化**（`emb_all.npz` + 会议 id，种子 42，单次置换）：

| 口径 | 同场基线 | d |
|---|---|---|
| 不排除自配对（＝存档 0.395 的口径） | 0.391 | 1.27 |
| 排除自配对（＝方法段声称的口径） | **0.360** | **1.41** |

差值约 0.03，与理论预期吻合：一个 8–9 对的会议里约 1/k 的行被自配对，自配对的 cos ≈ 0.61。
**两个严格基线（同来源 0.366、同来源×同敏感度 0.373）本身已排除自配对，不受影响。**

**三条可选处置**（我建议 A）：

- **A（建议）**：把同场基线改成排除自配对的数，即摘要的 "0.611 vs. 0.395" → "0.611 vs. 0.36"，
  §4.2 的 "0.611 observed against 0.395 … (d = 1.24)" → "… against 0.36 … (d = 1.4)"，
  Table 2 第一格同步。方法段不动（本来就是那么写的）。**这是核对自己的口径，且把效应量报大一点
  （更保守的方向是反的：修正后 d 变大，说明原报数是偏保守的）。**
- **B**：正文一个数字都不动，只在 Table 2 表注里补一句"the loosest baseline retains
  self-pairings, which makes the reported gap conservative"。
- **C**：不动。风险：若审稿人按 §3.3 的措辞自己复算，会得到 0.36 左右，与正文对不上。
